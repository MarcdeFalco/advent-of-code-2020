# Advent of Code 2020

Solutions pour l'Advent of Code 2020 (https://adventofcode.com/2020).
Les énoncés et les entrées ne sont pas inclus, à la demande du créateur d'Advent of Code : chaque solution lit son entrée dans un fichier `day2020_<jour>.txt` (par exemple `day2020_01.txt`) à récupérer sur le site.

Code écrit rapidement (« quick-and-dirty »), en Python, C et OCaml.
